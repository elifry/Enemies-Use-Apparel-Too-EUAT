# Enemies Use Apparel Too - EUAT

The purpose of this mod is to allow enemy humanoids to use apparel like the grenadier armor or turret pack. To do this, the mod converts apparel XML verb defs into ability defs so the AI can spot and use them, and it provides a way for ability use to consume charges from charged apparel (i.e. grenades from the grenadier armor).

## Note!!!!!!!

THIS MOD ADDS NO NEW ITEMS! It simply modifies the listed items to be usable by enemy AI.

This mod adds the defense pop tag to the listed packs, meaning any enemies that could spawn with those items (smokepop belt, shield belt, etc.) can spawn with the turret, jump, and hunter pack now.

The mod also adds the listed armors to spawn pools to allow them to spawn on enemies I deemed appropriate.

Items made usable for enemies:

Jump Packs

Locust Armor

Phoenix Armor

Grenadier Armor

Hunter Packs

Turret Packs

## Compatibility

This mod should work with almost any mods. Even ones that modify the items listed here as long as they're not relying on tweaking verbs.
